# AGENTS.md

miniace is a Dockerized AceStream engine stack (gluetun + acestream + kubo).
See README.md and docs/intro.md for technical details.

## Rules

1. **English only.** All content in this repository (code comments,
   documentation, commit messages, issues and PRs) must be written in
   English.
2. **No piracy.** This repository does not host piracy: no links to
   unauthorized streams, no copyrighted playlists, and no content that
   facilitates illegal access to protected material.
3. **Operator responsibility.** All responsibility for what is done with
   this code and its outputs lies with the operator who deploys and uses
   it. The authors and contributors assume no liability for misuse.
